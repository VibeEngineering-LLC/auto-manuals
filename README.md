# auto-manuals

Руководства пользователя и обучающие материалы по программам для гамма-спектрометрии, которые собираются
полуавтоматически: карта интерфейса строится по исходному коду и по живой программе, руководство — по устройству
отраслевых руководств (образец — руководство ЛСРМ SpectraLineXX), с градацией по уровню читателя
(начинающий / уверенный пользователь / профессионал).

## Подпроекты

| Папка | Программа | Состояние |
|---|---|---|
| [`becqmoni/`](becqmoni/) | BecqMoni Nuclear Edition | каркас руководства по сборке 2026.09.29.01, карта меню |

## Инструменты (`tools/`)

| Скрипт | Что делает |
|---|---|
| `designer_extract.py` | карта форм WinForms по `*.Designer.cs` и `*.resx` (подписи RU/EN, клавиши, обработчики `файл:строка`) |
| `check_designer.py` | независимый пересчёт карты регулярными выражениями — проверка экстрактора |
| `menu_tree_md.py` | дерево меню формы в markdown |
| `hdesk.py` | запуск процесса на скрытом рабочем столе Windows (тот же сеанс, экран пользователя не затрагивается) |
| `hd_probe.py`, `hd_list.py`, `hd_open.py` | на скрытом столе: список окон, снимок окна (`PrintWindow`), открытие пункта меню |
| `menu_walk.py` | обход меню живой программы через UI Automation — только раскрытие, без нажатия команд |
| `menu_diff.py` | сверка живого меню с картой по исходникам |

Требования: Windows, Python 3.10+, `pywinauto`, `pywin32`, `Pillow`.
